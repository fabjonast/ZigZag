# ZigZag
ZigZag is a study platform built for students who have ADHD or other neurodevelopmental conditions.
This platform turns the study material into interactive and entertaining formats, like games, flashcards,
mindmapping and word search.

## The Problem
Traditional studying is hard especially for students with ADHD, who often struggle with focusing on one task,
lack of motivation, working memory and procrastination. Existing tools, like Quizlet, Kahoot, etc, do not 
satisfy all the aspects listed above. They either focus on study games, flashcards, or test making, but not all 
at once.

## The Solution
ZigZag combines multiple study methods into a single platform.  
Notes -> Games: matching games, ...  
Notes -> flashcards: convert material into flashcards and customize the flashcards to fit the users personal aesthetic, 
or the materials aesthetic.  
Notes -> Mindmapping: map out the information in a way that it makes sense to the user. The user is able to 
customize it.  
Notes -> Word Search: auto-generate word search with the given material. Once the user finds a word, there will be a 
prompt where the user needs to fill in the definition of the found word.  
In case that the user loses interest in the current study method, they will be able to switch to a different one.

## Why ZigZag
The name ZigZag reflects how ADHD thinking works, jumping between ideas, taking a winding path to the same 
destination, while staying non-clinical.

## Scope
Some of the priority features include:
1. Note upload (text/PDF)
2. Content-engine: notes -> basic flashcard/game
3. Simple authentication and progress tracking
4. Basic sensory customization (theme, font size)
